RISC-V Operating System Kernel

Live Demo

A Unix-like kernel written from scratch in C and RV64 assembly. Sv39 three-level paging with per-process address spaces, preemptive multitasking, a custom KTFS filesystem, VirtIO block and console drivers, and an ELF loader. It boots under QEMU, mounts a filesystem from an emulated disk, and runs unmodified 1970s BSD games in user mode through real syscalls.
