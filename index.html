Operating System Kernel

I wrote a Unix-like kernel from scratch in C and RISC-V assembly. It does preemptive multitasking, Sv39 three-level paging with a separate address space per process, and a read-write filesystem (KTFS) with a write-back cache. On top of that sit fork, exec, and wait, and a shell of my own that handles I/O redirection, piping, and background jobs.

VirtIO block and UART drivers plus an ELF loader bring it up under QEMU: it boots from nothing, mounts a filesystem off an emulated disk, loads a binary into a fresh address space, and drops into user mode. The games it runs are unmodified 1970s BSD and Infocom programs compiled for RISC-V — the kernel underneath is the project. Recordings of it booting · Source

AlignAI

A real-time exercise form coach, built with a team of three at HackIllinois. I wrote the pose-comparison engine in Python: it aligns your workout against a reference video with dynamic time warping over normalized joint angles, so the score survives you moving at a different speed than the reference. It runs as a REST API on Modal.

I also set up the testing stack for the React and TypeScript frontend — Vitest for units, Playwright end-to-end — and cut search latency with a prefix-aware LRU cache in front of a third-party exercise API, with client-side debouncing that cancels stale requests. Try the demo · Source
